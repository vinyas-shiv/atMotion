# atMotion — Client-Side Image to Motion Video Converter

https://vinyas-shiv.github.io/atMotion/

100% Free, Private, and Client-Side Static Web App.

## Modes
- **Simple Mode (Default)**: Minimalist workflow with a single "Duration per Image" control in whole seconds (defaults to 6s, adjustable from 1s to 60s). Converts a single uploaded image into a pure still MP4 video, or merges multiple uploaded images into 1 combined slideshow MP4 where each image is displayed for your chosen duration.
- **Pro Studio Mode**: Full customization with Ken Burns camera motion paths, custom slide durations (1s to 15s), framerate toggles (24/30/60 FPS), mConverter 3-tier compression presets, procedural Web Audio soundtracks, and color grading filters.
